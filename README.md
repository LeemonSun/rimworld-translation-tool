# Sol Translation Tool 2.1

Локальный инструмент для Сола: контекстная память, воспроизводимый снимок мода, разбор XML и .NET-метаданных без выполнения оригинального кода, компактные вопросы, явная приёмка, сборка и изолированная игровая сверка.

Основная инструкция: [INTEGRATION.md](INTEGRATION.md).

`SOL.cmd open "D:\мод" --version 1.6 --mods brrainz.harmony`

Диагностика: `SOL.cmd doctor`. Состояние/следующий шаг возвращаются компактным JSON. Без аргументов START.cmd показывает команды. Старое окно: `python tool.py ui` (совместимость, не основной продуктовый цикл).

Требования этого ПК: Python 3.11 с tkinter; .NET 8 Runtime; уже установленная игра/Harmony и Framework csc для игровых проверок/патчей. Обычный анализ не требует игры запущенной, сети, API или новых установок. Используется существующий соседний conveyor.py. Native metadata reader собран из включённых исходников, без NuGet-пакетов. Пересборка: native/Metadata, dotnet build -c Release --configfile NuGet.Config; SDK 8.0.423 закреплён global.json.

Проверки: `python -m unittest -v test_product test_tool`; `python verify_ui.py`. Реальные контрольные переводы: verify_product.py; игровой baseline: verify_baseline.py. Последние две команды предназначены для разработческой проверки, не для обычного нового мода.

Steam-публикацию, обложки, пользовательские сохранения и оригинальные моды программа не меняет. Смысл принимается редактором; автоматическая проверка не является доказательством безошибочного русского текста.

## Публичный срез

Исходники версии 2.1. Рабочие базы и игровые файлы хранятся отдельно. Для анализа модов используйте Python 3.11. Для чтения метаданных DLL предварительно соберите проект native/Metadata. Игровые проверки требуют локальной установки RimWorld. Пути можно задать переменными RIMWORLD_GAME_DIR и RIMWORLD_HARMONY_DLL. Импорт старой памяти доступен при наличии соседней рабочей папки RimWorldTranslations.
